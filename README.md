# 🎵 AI Lofi Music Generator

An AI-powered music generator designed to create smooth, relaxing lofi beats with just a click.  
Built with modern web technologies, this project aims to combine AI and creativity for unique music experiences.

---

## 🌐 Website
Visit the live website here: **https://blankk1.github.io/Music-Generator/**

---

## 📌 Features
- 🎼 **AI-Generated Lofi Music** – Create unique and soothing music tracks instantly.
- 🎨 **Clean & Modern UI** – A minimal yet stylish design for the perfect listening vibe.
- 📱 **Responsive Design** – Works seamlessly on desktop, tablet, and mobile.
- 🎧 **Built-in Music Player** – Stream generated music directly from the website.
- 🖱 **Smooth Animations** – Scroll-triggered animations for a modern feel.


---

## 🚀 Deployment
This website is deployed using **GitHub Pages**.  
The live site automatically updates when changes are pushed to the `docs/` folder.
